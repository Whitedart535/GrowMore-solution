# GrowMore Solution

Modern FinTech and Loan Recovery Management Platform built with React, Vite, and CSS.

## Features
- **Collection Intelligence Visuals**: AI-driven recovery workflows and predictive analytics.
- **Campaign Excellence Engine**: Multi-channel debt resolution campaigns (WhatsApp, Voice Bot, SMS, Email).
- **Field Operations Management**: Real-time agent tracking and automated visit scheduling.
- **Native Calling & ACS Technology**: Integrated telecommunication infrastructure.

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation
```bash
npm install
```

### Running Locally
```bash
npm run dev
```

### Building for Production
```bash
npm run build
```
